# 0.0.1

First release of Larkdoc-sync. Publish Obsidian notes to Feishu or Lark Docs and sync updates through the local `lark-cli`.

- Sync and manage the current note from the Lark icon in its header.
- Check bindings and recent local results in the ribbon's Published files and Publish log tabs.
- Find CLI, document, sync, and advanced options in separate settings sections.
- Sync referenced local files as downloadable attachment cards from Obsidian. This does not change PDF page previews or add attachment uploads to the Git hook.

Desktop Obsidian 1.13.0 or later is required. This release uses the independent `larkdoc-sync` plugin ID. If upgrading, disable your old plugin without uninstalling it, then enable Larkdoc-sync to import existing bindings. See the [migration instructions](https://github.com/jipengju-GitHub/larkdoc-sync#moving-from-an-earlier-plugin).
